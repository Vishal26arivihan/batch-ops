Import the settings from Apps Script

Users, feature access, admin password, shared token and safety settings move from the old Apps Script dashboard to here. Personal tokens are not moved – every user saves their token once again (safer).

  1. Open the Apps Script project Batch OPS Dashboard → file AdminGS.
  2. Choose the function exportSettingsForMigration at the top → Run.
  3. Open Execution log and copy everything between the ----- lines.
  4. Paste it below and click Import. Do not send this text to anyone.

Settings were imported before (). Importing again replaces them – enter the admin password to confirm.
